# HeritEdge

HeritEdge is a Flutter-based mobile application focused on cultural heritage discovery and contribution. The app allows users to explore heritage sites, view location-based details, and contribute new heritage information through a structured and moderated system.

This project was built as a real-world focused application to practice scalable Flutter development, API integration, and clean state management.

---

## Features

- User authentication
- Heritage site listing and detailed views
- Location-based data using Google Maps
- Image upload and display
- Search and filtering functionality
- User contribution system with approval workflow
- Clean and modular UI components

---

## Tech Stack

- Flutter & Dart
- State Management: Provider / BLoC
- REST API integration
- Firebase (Authentication, Firestore, Storage, Notifications)
- Google Maps API
- Git & GitHub

---

## Architecture & Approach

- Separation of UI, business logic, and services
- Reusable widgets and modular structure
- API services handled outside UI layer
- Proper loading, error, and empty states
- Focus on readable and maintainable code

---

## Project Status

This project is under active development and is used as a learning-focused, production-style Flutter application. New features and improvements are added incrementally.

---

## Getting Started

1. Clone the repository  
2. Run `flutter pub get`  
3. Configure Firebase (if required)  
4. Run the app using `flutter run`

---

## Purpose

This project is intended to demonstrate hands-on Flutter development skills, including real-world app structure, state management, and backend integration.
